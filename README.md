# 국내 신용카드사 비교 대시보드

금융위원회 `금융통계신용카드사정보` OpenAPI를 조회하는 HTML/CSS/JavaScript 대시보드입니다.

## 실행

```powershell
cd C:\Users\coffe\Documents\ChatGPT\HD_prj
python app.py
```

브라우저에서 `http://localhost:4180`을 연 뒤, 공공데이터포털에서 해당 API의 활용신청 후 받은 서비스키와 기준년월(YYYYMM)을 입력합니다. Python 3만 있으면 되며, 별도 패키지 설치는 필요하지 않습니다.

서버를 실행한 PowerShell 창은 대시보드를 사용하는 동안 열어 두세요. 종료할 때는 해당 창에서 `Ctrl + C`를 누릅니다.

## 더 쉽게 실행하기

`카드사_대시보드_실행.bat` 파일을 더블클릭하면 Python 서버가 준비된 뒤 대시보드 주소를 자동으로 엽니다. 서버 창은 사용 중 닫지 말고, 끝낼 때 `Ctrl + C`를 누릅니다. 오류가 발생해도 창이 유지되므로 내용을 확인할 수 있습니다.

서비스키는 서버 파일이나 브라우저 저장소에 기록하지 않으며, 조회 요청에서만 사용합니다. API가 보내지 않은 지표는 `제공값 없음`으로 표시합니다.

`카드사별 영업실적 변화`에서는 시작·종료 연도(YYYY)와 카드사를 선택해 실제 `총계_이용실적`을 연도별로 집계한 변화 그래프를 볼 수 있습니다. 연도 입력값은 내부에서 1월~12월 범위로 처리하며, 원본은 분기 누계이므로 각 연도의 가장 최근 누계값을 연간 실적으로 사용합니다. 기본 조회를 완료하면 카드사 목록과 연도별 그래프 데이터도 자동으로 준비됩니다.
